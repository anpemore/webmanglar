Definicion de Variable

En programación, una variable es un espacio de memoria que se utiliza para almacenar datos. estos valores pueden cambiar durante la ejecución de un programa. Cada variable tiene un nombre único que se utiliza para referirse a ella en el código y un tipo que define qué tipo de datos puede almacenar (como números enteros, cadenas de texto, booleanos, etc.).

Condicional si (if)


el condicional "si" se expresa a través de la estructura condicional if. Esta estructura permite ejecutar cierto bloque de código si una condición específica se evalúa como verdadera (true). La sintaxis básica del condicional if varía ligeramente entre diferentes lenguajes, pero el concepto general es el mismo.


A grandes rasgos puede hablarse de estructuras organizativas centralizadas, que son aquellas en las que sobresalen los cargos directivos por encima del resto de integrantes; y descentralizadas, en las que los cargos delegan las responsabilidades en niveles intermedios o bajos.
